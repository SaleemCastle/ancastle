## Database

Ancastle Farms uses PostgreSQL with Prisma.

### Start PostgreSQL

```bash
docker compose up -d postgres
```
## Redis

### Start Redis:

```bash
docker compose up -d redis
```

## Local Development Infrastructure

Ancastle Farms uses Docker Compose for local infrastructure dependencies.

The Next.js web application and NestJS API run directly through Node.js/pnpm during development, while PostgreSQL and Redis run in Docker.

### Prerequisites

- Node.js
- pnpm
- Docker Desktop

### Environment Setup

Copy the example environment file:

```bash
cp .env.example .env
```

### Shared Packages

#### `@ancastle/types`

Contains reusable TypeScript types and API contracts shared between the frontend and backend.

Examples include:

- API response contracts
- Request/response types
- Shared enums and primitives
- Domain-facing DTO types

Database persistence models generated by Prisma must not be exposed through this package.

#### `@ancastle/validation`

Contains reusable Zod schemas for validating data at application boundaries.

Examples include:

- API request validation
- API response validation
- Form validation
- Shared field schemas

The validation package remains independent of Prisma and database implementation details.

### Application Boundary

Prisma models belong to the API persistence layer and must not be imported directly by the frontend.

Data exposed to the frontend should be mapped to explicit API contracts defined in the shared packages.
